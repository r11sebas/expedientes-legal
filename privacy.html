Política de Privacidad

Última actualización: octubre de 2026

Esta aplicación es una herramienta de uso personal, usada únicamente por el administrador del canal de YouTube "Expedientes del Internet" para automatizar la publicación de videos y consultar estadísticas del propio canal a través de la API de YouTube (YouTube Data API y YouTube Analytics API).

Qué datos se usan

La aplicación accede únicamente a datos del canal de YouTube del propio administrador: subir videos, programar su publicación, y leer estadísticas básicas (suscriptores, vistas, horas de reproducción). No recopila, almacena ni comparte datos de ningún otro usuario o canal de terceros.

Con quién se comparten los datos

Los datos no se comparten con terceros. Se usan exclusivamente dentro de esta aplicación para el funcionamiento del propio canal.
